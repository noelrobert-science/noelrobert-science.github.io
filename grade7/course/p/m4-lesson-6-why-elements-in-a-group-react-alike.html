🔁 Same group, same outer electrons · Coursebook page 93
Elements in the same group
Each atom in the same group has the same number of electrons in its outermost shell (valence electrons). This is why elements in the same group usually have similar chemical properties.
Elements in the same period
Each atom in the same period has the same number of electron shells.
💡 Noble gases are unreactive because their atoms have a full outer shell.
